# Data Safety draft

Use this as the working draft for Google Play Console.

- Data collected: No
- Data shared: No
- User accounts: No
- Location: No
- Personal info: No
- Health and fitness data: No data is collected or transmitted
- App activity analytics: No
- Crash analytics SDK: No
- Advertising ID: No
- Ads: No
- Third-party trackers: No
- In-app purchases: No

Local-only data:

- Daily session count
- Daily practice minutes
- Theme and audio preferences
- Custom breathing pattern

These values stay on the user's device in local app storage and can be removed by clearing app/site data. They can also be exported/imported by the user.
